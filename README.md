# Ferramenta de Imposto de Renda

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático da DIO, com o objetivo de criar uma ferramenta no Microsoft Excel para organizar e centralizar informações relevantes para a declaração do Imposto de Renda.

## 🎯 Objetivos

- Organizar informações necessárias para a declaração do Imposto de Renda.
- Facilitar o registro e a consulta de dados.
- Aplicar conhecimentos de Excel na construção de uma ferramenta prática.
- Documentar o projeto utilizando o GitHub.

## 🛠️ Tecnologias utilizadas

- Microsoft Excel
- GitHub
- Markdown

## 📂 Arquivos do projeto

O repositório contém a documentação do projeto e será utilizado para disponibilizar a planilha desenvolvida.

## 📚 Aprendizados

O desenvolvimento deste projeto permite praticar a organização de dados em planilhas, a estruturação de informações e a documentação técnica por meio do GitHub.

## ⚠️ Observação

A ferramenta tem finalidade organizacional e não substitui os sistemas oficiais da Receita Federal ou a orientação de um profissional contábil.
